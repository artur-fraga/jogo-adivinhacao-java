# jogo-adivinhacao-java
Jogo simples de adivinhação de números. 
Construído com Java utilizando Math.random(), para gerar um número aleatório dentro de uma variável. 

## Funcionalidades
- Usuário define um número máximo;
- O sistema gera um número secreto aleatório;
- Fornece dicas (maior/menor) a cada palpite;
- Informa quando o usuário acerta.

## Possíveis melhorias
- Validar entradas não numéricas;
- Contar e exibir número de tentativas;
- Perguntar se o usuário quer jogar novamente;
- Adicionar níveis de dificuldade.

## Objetivo
- Projeto desenvolvido com o intuito de praticar lógica de programação, estruturas condicionais, entrada de dados e geração de números aleatórios em Java.
